# UML Visual Studio

Herramienta web para generar diagramas UML desde codigo, editarlos visualmente y exportarlos con un acabado profesional.

## Stack inicial

- React 19
- Vite 8
- TypeScript 6
- React Flow
- Monaco Editor
- Zustand
- Tailwind CSS

## Comandos

```bash
npm install
npm run dev
npm run build
```
